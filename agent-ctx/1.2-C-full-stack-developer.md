## Honestidad técnica Cloudflare
- Workers AI como proveedor primario (no OpenAI/Anthropic).
- Fallback determinista obligatorio documentado (cuotas, latencia, disponibilidad).
- KV no autoritativo para permisos (memoria de request).
- D1 `audit_logs` append-only + archive a R2 cifrado para retención larga.
- Cloudflare Queues para colas por canal+prioridad.
- WebSockets vía DO para notificaciones internas.
- DO efímero + D1 durable para métricas operativas.
- R2 como warehouse y archive.
